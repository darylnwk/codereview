What it is

Your agent wrote the diff, so it is the wrong reviewer. It already decided the change was right.

Review grade sees only the diff. It reports that change when the new behavior is wrong, even if the edit looks helpful.

If nothing breaks, the list is empty. A failed review spends nothing, and there is no score.
