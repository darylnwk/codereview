§02

Your agent sends the diff, reads the findings, fixes, and calls again.

Each pass is one review. What comes back is four fields, not a conversation: only what breaks, with the fix. No style nits. When the list comes back empty, the loop is done.

  1. file

    The path, exactly as it appears in the diff.

  2. line

    The new-side line number. Not a range, not a hunk.

  3. breaks

    One sentence on the behaviour that is now wrong. No style nits, no praise.

  4. fix

    One line you could paste. If it needs more than a line, it says so.

§05

It is not for sale until it catches the bugs we already know about.

Before we take money, the reviewer runs against a private set of pull requests with known, planted defects. It never sees the answer key. A separate matcher counts what it caught.

The ship line is 85% of planted defects caught. It has not reached that line yet. If a later model or prompt drops it below 70%, we stop selling.
